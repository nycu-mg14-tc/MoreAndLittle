解鎖你的管理頁

使用專案擁有者的 GitHub 管理金鑰，才能新增內容。金鑰只在本次頁面開啟期間使用，重新整理或離開後需要再次輸入。

已預填本站的專案；一般不需要更改。

請勿填寫 GitHub 密碼，也不要把金鑰傳給他人。

第一次使用：如何取得管理金鑰？
  1. 先確認完整網站已上傳到自己的 GitHub 專案。
  2. 開啟 GitHub 金鑰設定 ↗，設定名稱與到期日。
  3. Resource owner 選自己；Repository access 選 Only select repositories，僅勾選這個網站的專案。
  4. Repository permissions 的 Contents 選 Read and write，其餘維持預設。
  5. 產生後，將金鑰保存在自己的密碼管理工具，並貼到上面的欄位。

管理頁的入口可以公開；真正的寫入權限由 GitHub 驗證。請讓這個專案只有你具有寫入權限。

新增知識

儲存後會等待網站更新，通常需幾分鐘。所有訪客都能看到發布的內容。
